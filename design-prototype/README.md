# Концепт премиальной главной страницы 3Д Вещь

Изолированный HTML-макет для оценки нового визуального направления. Он не подключён к сборщику `build/build.js`, не заменяет текущую главную страницу и не меняет опубликованный сайт.

## Что уже проверено

- Цены четырёх товаров сверены с `content/products-autumn.json`: «Волна» — 1 700 ₽, ваза-тыква — 800 ₽, шкатулка-грибочек — 750 ₽, осенний гном — 650 ₽.
- Фотографии используют существующие JPEG-файлы из `public/images/`, а не предполагаемые WebP-версии.
- Ссылки ведут на реальные карточки товаров: там остаются текущие корзина и оформление заказа.
- Вёрстка содержит мобильные правила и уменьшение анимации для `prefers-reduced-motion`.

## Важное ограничение тестирования

Прототип открыт отдельно от домена `3dvesh.ru`. Поэтому нельзя безопасно использовать корзину через `localStorage` прямо из прототипа: браузер разделяет хранилища разных доменов. Сейчас кнопки товара ведут на соответствующие опубликованные карточки, где работают существующие покупательские сценарии. Прямое добавление в корзину с новой главной нужно проверять после размещения тестовой версии на том же домене/в защищённой staging-среде.

## Визуальная идея

- Контрастная тёмная hero-сцена с главным предметом и эмоциональным первым впечатлением.
- Тёплый редакционный каталог, где легко сравнить товары и цены.
- Отдельный заметный переход к заказу изделия по собственной идее.
- Мобильная компоновка, крупные зоны нажатия, без обязательной анимации и тяжёлых 3D-эффектов.

**Публикация не менялась.** До отдельного согласования концепт не подключается к главной странице.
