# Концепт премиальной главной страницы 3Д Вещь

Это изолированный HTML-макет для обсуждения визуального направления. Он не подключён к сборщику `build/build.js`, не заменяет главную страницу и не меняет опубликованный сайт.

## Открытие
Откройте `design-prototype/premium-editorial-home.html` в браузере. Для просмотра фотографий макет использует публичные изображения с `https://3dvesh.ru/images/`; если какой-либо путь изменится, фото нужно синхронизировать с текущим каталогом.

## Идея
- Контрастная тёмная hero-сцена для узнаваемого объекта и эмоционального первого впечатления.
- Тёплый редакционный каталог для спокойного выбора товаров и цен.
- Отдельный CTA на заказ по своей идее.
- Мобильная компоновка, крупные зоны нажатия, отсутствие обязательной анимации и тяжёлых 3D-эффектов.

## Перед внедрением
Проверить актуальные цены и фото с `content/products-autumn.json`, а также целевые URL карточек. Макет не содержит настоящего добавления в корзину; в рабочей версии необходимо подключить существующий `cart.js` и сохранить оформление заказа/Telegram Worker.
