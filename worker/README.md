# printlab-order-notifier

Маленький Cloudflare Worker: принимает заказ/заявку с 3-d-shop.ru и
пересылает заказы и все сообщения AI-чата вам личными сообщениями в Telegram через Bot API. AI отвечает через OpenAI Responses API. Существует
отдельно от статического сайта, потому что токен бота — секрет, а сайт
на Timeweb — чистая статика без сервера, класть токен в клиентский JS
небезопасно (любой посетитель откроет исходный код и сможет писать от
имени бота).

## Разовая настройка (выполняйте в СВОЁМ терминале, не через ассистента —
## секреты не должны попадать в переписку)

1. Установите Wrangler (CLI Cloudflare), если ещё нет:
   ```
   npm install -g wrangler
   ```

2. Авторизуйтесь (откроется браузер):
   ```
   cd worker
   wrangler login
   ```

3. Узнайте токен бота `@Shop3D_online_bot` — он у вас уже должен быть
   (тот же, что использует Telegram-бот магазина). Если нет — получите
   у @BotFather в Telegram (`/mybots` → выбрать бота → API Token).

4. Узнайте свой числовой Telegram chat ID (не @username, а число) —
   например, напишите что угодно боту `@userinfobot` в Telegram, он
   пришлёт в ответ ваш `Id`.

5. Задайте секреты (команда спросит значение в защищённом вводе,
   ничего никуда не логируется):
   ```
   wrangler secret put BOT_TOKEN
   wrangler secret put OWNER_CHAT_ID\n   wrangler secret put OPENAI_API_KEY
   ```

6. Задеплойте:
   ```
   wrangler deploy
   ```
   В выводе будет URL вида
   `https://printlab-order-notifier.<ваш-субдомен>.workers.dev` —
   пришлите его ассистенту (сам URL не секрет), он впишет его в
   `public/js/order-api.js` на сайте.

## Проверка

```
curl -X POST https://printlab-order-notifier.<субдомен>.workers.dev \
  -H "Content-Type: application/json" \
  -d '{"kind":"order","name":"Тест","contact":"@test","items":[{"title":"Тест-товар","qty":1}],"method":"Самовывоз в Брянске"}'
```
Должно прийти сообщение в Telegram и вернуться `{"ok":true}`.

## Если что-то пошло не так на сайте

Сайт при неудачном запросе к этому Worker (не задеплоен, сеть недоступна
и т.п.) не теряет заказ — показывает тот же текст заказа с кнопками
«Скопировать» и «Открыть Telegram-бота», чтобы покупатель мог отправить
его вручную. См. `public/js/checkout.js` / `custom-order.js`.
\n### AI-чат\nПосле добавления секрета `OPENAI_API_KEY` чат на сайте использует модель `gpt-5.6-luna` (можно переопределить через `OPENAI_MODEL` в Worker). AI отвечает на вопросы, ненавязчиво помогает выбрать товар и собирает для заказа ФИО, город и телефон. В Telegram приходит уведомление о начале диалога, каждое сообщение клиента и AI, а отдельным сообщением — готовый заказ.\n
